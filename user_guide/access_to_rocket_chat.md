# How to access the WEED CU Rocket Chat channel
Access to Champions Users' dedicated Rocket Chat channel


### 1. Register in the k.HUB
https://integratedmodelling.org/hub/#/register

<img width="480" height="258" alt="image" src="https://github.com/user-attachments/assets/8a6877f7-7c1b-42e0-b13a-4ca968ad065f" />

These steps are the same for any application in ARIES, so you can use this documentation:
https://seea.un.org/sites/default/files/documents/how_to_access_aries_for_seea_16mar22.pdf

### 2. Open the link to access the channel
Link: https://go.rocket.chat/invite?host=chat.integratedmodelling.org&path=invite%2FAcftca

Select the web application (or download the desktop app if you prefer)

<img width="480" height="120" alt="image" src="https://github.com/user-attachments/assets/992469cc-cd00-4113-9bce-e79e5b515c7c" />



Use the same username :key: and/or email :email: and password :lock:

[These are the same credentials from k.HUB, as in **1.**](https://github.com/integratedmodelling/esa.weed.aries/edit/feature/user_guide/user_guide/access_to_rocket_chat.md#1-register-in-the-khub)

You'll be directly connected to the channel in the web browser
